# eCard – Tự Tạo Thiệp

Ứng dụng Android tạo thiệp chúc mừng, thiệp chia buồn, thiệp mời.

- 4 phong cách: Đông phương Cổ điển / Hiện đại, Tây phương Cổ điển / Hiện đại; 7 bảng màu (có tông tang lễ Trắng – Đen)
- 23 dịp: Tết, sinh nhật, mừng thọ, cưới, tân gia, khai trương, 8/3, 20/10, 20/11, Trung thu, Giáng sinh, chia buồn, tưởng nhớ, lời mời…
- Thư viện lời chúc / chia buồn / lời mời / lời hay ý đẹp, mỗi câu đủ 3 ngôn ngữ: Việt – Anh – Trung (Phồn thể)
- Dùng ảnh của bạn làm nền thiệp
- Lịch đếm ngược Lễ, Tết, sinh nhật, ngày giỗ (âm lịch, tự đổi sang dương lịch), thông báo nhắc trước
- Lưu vào thư viện ảnh (Pictures/eCard) và chia sẻ qua Zalo, Facebook, Messenger, Instagram…

## Tải APK
Vào mục **Releases → latest** để tải `eCard.apk`. Mỗi lần cập nhật mã nguồn, GitHub tự build lại.
Khoá ký cố định nên bản mới cài đè lên bản cũ, không mất dữ liệu.

Yêu cầu: Android 10 trở lên.
